Pasang KantorKu

Aplikasi dapat dipasang langsung dari browser. Tidak perlu membuka Google Play atau Microsoft Store.

Buka dan Pasang Unduh EXE Windows

Android / Chrome / Edge

  1. Buka Buka dan Pasang.
  2. Pilih Pasang Aplikasi di bagian atas.
  3. Jika belum muncul, buka menu browser lalu pilih Pasang aplikasi.

Windows / Chrome / Edge

  1. Buka aplikasi melalui Buka dan Pasang.
  2. Pilih ikon pasang di bilah alamat atau tombol Pasang Aplikasi.
  3. Konfirmasi pemasangan. KantorKu akan muncul sebagai aplikasi desktop.

iPhone / iPad / Safari

  1. Buka aplikasi melalui Safari.
  2. Ketuk Bagikan.
  3. Pilih Tambah ke Layar Utama.
